# Photos RS6 — dépose-les ici

Le site `obsidian-rs6.html` est **photo-ready** : il affiche automatiquement tes
vraies photos dès qu'elles sont présentes dans ce dossier, et retombe sur
l'illustration SVG si un fichier manque. **Aucune modification de code nécessaire.**

## Fichiers attendus (noms exacts)

| Fichier | Vue | Utilisé dans |
|---------|-----|--------------|
| `rs6-side.jpg`  | Profil (côté)        | Hero épinglé + Collection « Profil » |
| `rs6-front.jpg` | Face / 3-4 avant     | Collection « Face » |
| `rs6-rear.jpg`  | Arrière / 3-4 arrière| Collection « Signature arrière » |

- Formats acceptés : `.jpg`, `.png`, `.webp` (garde le nom `rs6-side.jpg`, etc.).
- Idéalement détourées sur fond transparent (PNG/WebP) pour un rendu showroom,
  mais les photos sur fond clair fonctionnent aussi.
- Largeur conseillée : 1600–2400 px.

## Comment les ajouter (depuis GitHub, sans coder)

1. Va sur le repo `hichamwear-ctrl/claudeskill`, dans le dossier `assets/`.
2. **Add file → Upload files**, glisse tes 3 photos (renommées comme ci-dessus).
3. Commit. C'est tout — le site les affichera automatiquement.
