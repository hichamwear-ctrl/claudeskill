Pour changer une photo, remplacez le fichier du même nom (le mapping est dans
`assets/app.js` → `IMG`). Si un fichier manque, un dégradé miel élégant + le nom
du produit s'affiche automatiquement (aucune image cassée).

Images d'ambiance optionnelles : `../hero.jpg` (accueil) et `../about.jpg` (À propos).
